# Fullstack 100

现代软件工程与全栈开发的 100 个核心关键词知识体系。

本项目通过知识地图、概念讲解、工程案例和阶段测试，帮助开发者建立可迁移的工程认知，而不是记忆某个技术栈的工具清单。

## 内容

- [100 个核心关键词知识地图](docs/knowledge-map.md)：10 个知识模块、100 个关键词、核心基础 TOP 20、知识关联和学习路径。
- [学习提示词](prompts/README.md)：深度学习、跨概念关联分析、掌握程度测试。
- [贡献指南](CONTRIBUTING.md)：内容结构、修改流程和提交约定。

## 知识模块

| 模块 | 编号 | 核心问题 |
|---|---:|---|
| 计算机科学基础 | 1–10 | 计算机程序如何运行 |
| 编程语言与编程范式 | 11–20 | 如何编写正确、可维护的程序 |
| 数据结构与算法 | 21–30 | 如何组织数据和解决计算问题 |
| 操作系统与计算机网络 | 31–40 | 程序如何运行及如何通信 |
| 前端与浏览器 | 41–50 | 浏览器如何渲染和交互 |
| 后端与服务端开发 | 51–60 | 如何构建可靠的业务服务 |
| 数据库与缓存 | 61–70 | 如何存储、查询和管理数据 |
| 软件工程与研发效能 | 71–80 | 如何长期维护和交付软件 |
| 系统架构与分布式系统 | 81–90 | 如何组织可靠的复杂系统 |
| 人工智能与 Agent 工程 | 91–100 | 如何构建可用、可靠的 AI 应用 |

## 学习方式

每次学习 3～5 个关键词，依次完成：

1. 理解概念：它是什么，解决什么问题。
2. 理解原理：它如何工作，为什么这样设计。
3. 工程实践：在真实项目中如何使用。
4. 关联学习：它与其他知识点有什么联系。
5. 主动测试：通过场景题检验理解程度。

## 优先级

- **P0**：必须深入理解的核心基础。
- **P1**：应熟练掌握并能用于项目。
- **P2**：理解原理、适用场景和技术边界即可。

## 适用范围

项目以通用软件工程知识为主，覆盖前端、后端、数据库、系统架构和 AI Agent。具体语言、框架和工具作为解释原理的实例，不构成唯一技术路线。
